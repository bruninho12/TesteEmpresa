# NeuroFood Interface Mockups

This directory contains the HTML mockups and screenshots for the NeuroFood intelligent food factory interface system. NeuroFood transforms a food industry into a digital living organism where each production batch is monitored like a cell within a biological system.

## Mockup Files:
1. **main-dashboard.html** - Main Dashboard with IVA (Índice de Vitalidade Alimentar)
   - Features: IVA gauge, real-time monitoring, preventive alerts, production line status
   - Screenshot: neurofood-main-dashboard.png

2. **digital-dna.html** - Digital DNA Traceability interface
   - Features: QR code generator, DNA digital structure, ingredient origins, certifications
   - Screenshot: neurofood-digital-dna.png

3. **preventive-ai.html** - Preventive AI Dashboard
   - Features: Neural network visualization, risk pattern detection, learning cycle
   - Screenshot: neurofood-preventive-ai.png

4. **digital-twin.html** - Digital Twin interface
   - Features: 3D virtual simulation, failure prediction, interactive control panel
   - Screenshot: neurofood-digital-twin.png

## Assets:
- **assets/neurofood-logo.svg** - NeuroFood logo (brain + molecule design)
- **assets/neurofood-styles.css** - Common futuristic biological theme styles

## Design Features:
- Modern, futuristic aesthetic appropriate for intelligent food production
- Biological/natural color scheme (greens, blues, organic gradients)
- High-tech appearance with animated elements and glowing effects
- User-friendly interface despite advanced functionality
- Responsive design for different screen sizes
- Real-time data visualization and interactive controls

## Technologies Used:
- HTML5 for structure
- CSS3 with advanced animations and gradients
- SVG for scalable graphics and logo
- Responsive grid layouts
- Custom animations and visual effects

To view the mockups, open the HTML files in a web browser or serve them via a local web server.
